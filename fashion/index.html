MAKE CONTRACT

Make 시나리오가 받을 데이터

{
  "event": "fashion.tryon.requested | fashion.batch.requested",
  "job_id": "uuid",
  "provider": "auto | fashn | claid | thenewblack",
  "project": "프로젝트 이름",
  "category": "one-pieces",
  "person": { "name": "model.jpg", "data_url": "data:image/..." },
  "garment": { "name": "dress.jpg", "data_url": "data:image/..." },
  "prompt": "추가 지시",
  "callback_expected": {
    "status": "completed",
    "output_url": "https://...",
    "database_id": "상품 또는 결과 레코드 ID"
  }
}

웹훅이 JSON 응답으로 output_url과 database_id를 반환하면 작업 카드에 자동 표시됩니다. 장시간 비동기 API는 Make 내부에서 폴링하거나 별도 콜백 시나리오를 사용하세요.
