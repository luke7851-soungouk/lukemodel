Privacy / 개인정보

Last updated: 2026-09-25 · Honest short notice for a static GitHub Pages app.

What we store

FaceLook runs in your browser. Model catalogs, preferences, and share packs use localStorage. Larger image/video blobs use IndexedDB. There is no lukemodel application server that syncs your library across devices yet.

페이스루크는 브라우저에서 동작합니다. 카탈로그·설정·공유 팩은 localStorage, 큰 이미지·영상은 IndexedDB에 저장됩니다. lukemodel 클라우드 동기화 서버는 아직 없습니다.

API keys (BYOK)

Provider keys you enter (Fal, Replicate, OpenAI, Google AI, Higgsfield, etc.) stay in your browser storage. They are not sent to lukemodel.com. Generation requests go from your browser to the provider you chose.

입력한 API 키는 브라우저에만 남으며 lukemodel 서버로 전송되지 않습니다(앱 백엔드 없음).

Login

Optional Google / Kakao / Naver sign-in is used for local identity scoping (e.g. per-account AI slots). We do not operate a FaceLook account database on our own servers.

Public gallery & accounts / 공개 갤러리·계정 (Supabase)

Files you upload or generate and choose to share (and Higgsfield studio results, which are shared automatically) are stored in a Supabase project (Seoul region) and are visible to everyone. To let you delete your own items, the site may create an anonymous account for your browser (a random ID kept in this browser's localStorage). If you connect GitHub or an email address, Supabase stores that login identifier (email or GitHub account ID/username) so you can manage your items from other devices. We do not sell or share this data. You can delete your items yourself; ask via GitHub issue to delete your account.

공유한 파일과 힉스필드 스튜디오 결과(자동 공유)는 Supabase(서울 리전)에 저장되어 누구나 볼 수 있습니다. 내 작품을 직접 삭제할 수 있도록 브라우저마다 익명 계정(무작위 ID, 이 브라우저 localStorage에 보관)이 만들어질 수 있습니다. GitHub·이메일을 연결하면 다른 기기에서 관리할 수 있도록 로그인 식별자(이메일 또는 GitHub 계정 ID/이름)가 Supabase에 저장됩니다. 판매·제3자 제공은 하지 않으며, 작품은 직접 삭제할 수 있고 계정 삭제는 GitHub 이슈로 요청하세요.

Traffic counting / 트래픽 집계

We count anonymous aggregate pageviews, approximate unique visitors (browser localStorage first-visit flag), coarse traffic-source buckets, and a few feature events (upload / AI generate / share code / download). Counts go to a third-party public counter service (Abacus; fallback beacon). We do not store IP addresses or personal profiles for this. Keys are public; numbers are approximate.

익명 집계만 합니다(페이지뷰·대략적 순 방문자·유입 경로 버킷·주요 기능 이벤트). 제3자 공개 카운터 서비스를 사용하며, 저희 쪽에서 IP·개인 프로필을 저장하지 않습니다. 광고 차단기 등으로 집계가 빠질 수 있습니다.
